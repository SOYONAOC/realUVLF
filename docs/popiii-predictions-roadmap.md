# Pop III 后续预测工作记录：He II、PISN 与 21 cm MAP

记录日期：2026-09-10。用户确认将三项预测及其后续工作列入项目记录。
研究路线沿用[项目总览 slides](../slides/auroralf_project_overview/auroralf_project_overview.pdf)
第 1 页：用 Pop III 解释高红移 UVLF，再用同一套模型预测 He II、PISN 和
21 cm，接受独立观测检验。本轮明确将 21 cm 的空间 MAP 列为目标产物。

## 共同模型与当前状态

本轮参考模型为随机首次越阈、单次 Pop III 爆发，成星效率 εb=0.03：
log10(q)~N(0.5,1.5²)，Mstar,III=εb(Ωb/Ωm)Mh(tb)。沿用现有 Pop II
历史，以及零金属 logE SSP（1–500 Msun，Mc=60 Msun，σlnM=1）。
这是一套待检验的研究模型，εb=0.03 尚未由联合观测拟合确定。

| 项目 | 当前状态 | 目标产物 |
|---|---|---|
| UVLF 基础 | 已有 z=12.5 的 R032、z=14.5 的 R024–R027 | 三项预测共享的模型、历史和样本身份 |
| He II 1640 | 已完成初步 Case-B 线光度函数、通量分布、纯 SSP 年龄诊断 | 与 JWST 同条件比较的线通量、总星系 EW、检出/未检出统计 |
| PISN | 旧模型已有事件率诊断；当前 εb=0.03 模型尚待计算 | 本征爆炸率及巡天可探测事件数 |
| 21 cm MAP | 当前 εb=0.03 模型尚未完成空间预测 | 同一恒星形成模型驱动的 21 cm 亮温空间图及相应统计 |

旧 PISN 曲线不能直接作为当前随机阈值模型的预测。现有独立 MAH 样本及
HMF 权重也不提供空间坐标、聚集或气体场，不能直接拼成物理一致的 21 cm MAP。

## 共同准备工作

- [ ] 固定并记录参考配置、运行种子、样本身份、宇宙学、SSP 版本和输入哈希；
  三项预测共用同一套 Pop III 形成质量、爆发时间及恒星族参数。
- [ ] 建立统一的恒星族输入表：UV、He+ 电离光子、H 电离光子、LW 辐射、
  恒星寿命、终末命运及所需反馈产额。不同文献输入的适用范围与不一致处须显式记录。
- [ ] 明确当前模型未闭合的原初气体存续、富集和反馈；未来新增物理会改变
  形成历史时，同时重算 UVLF 与受影响的预测，不能只更新某一探针。
- [ ] 根据事件率演化和空间场计算的需要，确定红移覆盖与时间分辨率；目前
  z=12.5、14.5 两个观测时刻的样本不能替代完整的宇宙演化输出。
- [ ] 将 MC 误差、时间/空间分辨率误差、SSP/IMF 误差和气体/选择效应分开评估。

## 1. He II 1640：从线强预测到 JWST 约束

已完成内容见 [He II 研究记录](heii-random-q-study.md)及
[当前结果 slides](../slides/heii_random_q_20260910/heii_random_q.pdf)。
使用与 UV 匹配的 Raiter、Schaerer & Fosbury (2010) logE 谱线表，按实际
爆发质量和年龄计算；不是直接采用 VH15 的恒定 SFR 转换系数。

- [x] 复用 R032、R024–R027，校验运行产物，并逐样本核对原 UV 光度。
- [x] 计算 Case-B He II 光度函数、累积通量分布及 UV 亮样本的条件统计。
- [x] 检验年轻 SSP 年龄插值；已发现其影响可超过 MC 标准误。
- [ ] 获取或生成同一 logE IMF 更细的 0–3 Myr SSP，验证年龄插值收敛。
- [ ] 明确电离光子逃逸、H/He 吸收竞争、气体密度和电离参数，评估实际线强。
- [ ] 补齐 Pop II、Pop III 在 1640 Å 的恒星与星云连续谱，计算总星系 EW；
  气体响应改变时自洽更新 UV 选择。
- [x] 录入 GHZ2、GS-z14-1 的红移、UV 星等、线通量/上限、误差及论文的线宽、
  孔径与透镜处理说明；保存机器可读来源。尚未组成正式联合约束样本。
- [x] 绘制近邻红移样本的 UV–He II 条件分布，叠加 GHZ2 实测值和 GS-z14-1
  上限；完成分箱及插值敏感性检查，见 [观测对照记录](heii-observation-comparison.md)。
- [ ] 补齐目标红移样本、UV 误差及仪器响应；Hebe 的 z≈10.6 团块需另行匹配。
- [ ] 将检出、未检出及观测选择统一纳入比较，并结合金属线、可测氢线评估
  Pop II、AGN、冲击等来源，区分“检测到 He II”和“支持 Pop III”。

完成标准：得到可复现的条件分布、观测对照图及明确假设下的模型约束。
固定通量门槛的比例不能直接称作 JWST 探测率。

## 2. PISN：从同一批恒星到可探测瞬变

- [ ] 为参考 IMF 选定有来源的恒星寿命与 PISN 终末命运模型，记录质量、
  金属丰度及其他适用条件；PISN 质量区间不由 UV SSP 上限直接确定。
- [ ] 从每次 Pop III 形成质量及 IMF 计算 PISN 产额，将寿命延迟映射到
  爆炸时刻，得到随红移变化的本征事件率，单位 yr−1 Mpc−3（源参考系）。
- [ ] 检查有限恒星数/随机 IMF 对事件计数的影响，并与 He II 的 IMF 假设一致。
- [ ] 选定有来源的 PISN 光变曲线/光谱，转换到目标巡天的观测波段，处理
  红移、距离、时间膨胀及必要的衰减。
- [ ] 纳入巡天面积、深度、观测节奏、有效可见时间及选择效率，预测观察者
  时间内的检出数。源参考系事件率到观测事件数的转换须包含 (1+z)。
- [ ] 与适用的瞬变检出或未检出比较；旧模型结果仅作标注清楚的历史对照。

完成标准：同时提供本征事件率曲线与指定巡天条件下的预期检出数，避免将
“发生多少次爆炸”混同于“望远镜能看到多少次”。

## 3. 21 cm MAP：把恒星形成模型接入空间气体与辐射场

- [ ] 选择并记录空间计算框架及真实输入：密度场、晕分布/历史、盒子尺度、
  空间和时间分辨率、初始条件。需要建立随机爆发模型与空间晕群的对应关系。
- [ ] 将同一套 Pop II/III 恒星族的辐射产额接入 Lyα 耦合、加热和电离计算；
  X 射线来源及其他新增参数单独定义，不能由 UV/He II 表自动推定。
- [ ] 计算中性氢比例、气体动温、自旋温度及所需速度效应，产生有明确坐标、
  红移和 mK 单位的 21 cm 亮温 MAP。
- [ ] 视目标需求保存共同时间切片或 light cone；画出同初始条件下 Pop II
  基线与加入 εb=0.03 Pop III 的地图及差异，区分真实空间结果与示意图。
- [ ] 从地图提取全局平均信号和功率谱等可比较统计，检验盒子大小及分辨率。
- [ ] 针对选定 21 cm 观测加入角/频率分辨率、噪声、前景和可用模式；JWST
  提供星系端的信息，21 cm MAP 本身需与相应射电观测衔接。

完成标准：得到可追溯的物理空间图、基线差异及观测可比统计。全局平均
21 cm 曲线不能代替本次登记的 MAP 目标。

## 执行顺序与记录要求

1. 先固定共享输入，优先处理已发现的年轻 He II SSP 分辨率问题。
2. 完成 He II 的正式观测对照；建立当前模型的 PISN 寿命/产额和事件率计算。
3. 确定 21 cm 空间框架及输入，再实现 MAP；按各自观测条件推进三项检验。
4. 最终评估同一个 εb=0.03 模型能否同时解释 UVLF、He II、PISN 和 21 cm，
   不为每个探针私自使用不同的形成历史、IMF 或效率。

各阶段更新本记录与[实验日志](visbal-duty-experiment.md)，保存输入、代码版本、
运行清单、单位、误差和复现入口；阶段性结论以 slides 展示。复用现有样本，
新增计算遵循项目 SLURM 规则；不自动重复四批。当前登记的是后续工作，
不表示三项预测均已完成，也不启动新的计算任务。
